# HX-CentCom requirements and test coverage

This page maps each owner requirement of work unit WU1 to the feature that meets it and to the tests that check it. Report this coverage apart from test counts. A passing suite does not show that a requirement is met. [Issue #1](https://github.com/HX-Infratstructure/HX-CentCom/issues/1) tracks the work unit.

## Status values

- **built**: the feature is in this tree.
- **tested**: automated tests in this tree check it. The pull request records the run, its commit, and its result.
- **live NOT_RUN**: nobody has checked it on the deployed hosts. Nothing runs on HX-7, HX-9, or HX-15 until the owner's GOs ([OPERATIONS.md](OPERATIONS.md#deploy-to-the-hx-hosts)).
